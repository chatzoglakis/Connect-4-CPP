A command-line Connect Four game built in C++ featuring a custom AI opponent powered by the Minimax algorithm

##  Features
* **Player vs. Player (PvP):** Play locally with a friend.
* **Player vs. AI (PvE):** Test your skills against a smart AI.
* **Dynamic Board Sizing:** Choose a custom board size ranging from 5x5 to 9x9 before starting the game.
